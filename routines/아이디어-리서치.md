# 💡 아이디어 리서치 루틴 템플릿

몇 시간마다 Claude가 트렌드를 리서치해서 **내 브랜드·채널에 맞는 아이디어**를 만들고,
Clawd가 메뉴 막대와 Touch Bar에서 "💡 아이디어!" 말풍선으로 하나씩 던져 주게 하는 예약 작업입니다.

## 만드는 법

1. 아래 "작업 내용"을 복사해서 `[대괄호]` 부분을 내 상황에 맞게 바꿉니다.
2. Claude 데스크톱 앱에서 아무 Code 세션이나 열고 이렇게 말합니다.
   > 이 내용으로 3시간마다(9시~21시) 도는 예약 작업 만들어 줘.
   > (바꾼 작업 내용 붙여 넣기)
3. 만든 뒤 한 번 "지금 실행"해서 웹 검색·파일 쓰기 권한을 허용해 두면, 다음부터는 묻지 않고 돕니다.

예약 작업은 Claude 앱이 켜져 있을 때 실행되고, 꺼져 있었으면 다음에 켤 때 실행됩니다. 실행할 때마다 Claude 사용량이 듭니다.

## 작업 내용

```
#clawd-idea-routine
(위 태그는 Clawd 앱이 이 작업을 알아보는 표시이니 지우지 마세요. 이 작업이 끝나면 "완료!" 대신 아이디어 말풍선으로 알려 줍니다.)

## 목표
[리서치할 곳: 예) 지금 미국 인스타그램 릴스]에서 가장 톡톡 튀고 기발하면서 조회·공유·저장 반응이 좋은 콘텐츠를 리서치하고,
그걸 바탕으로 "[브랜드 이름]"에 맞는 콘텐츠·기획 아이디어를 만든다. 결과는 보고서 한 편과 Clawd가 읽는 아이디어 목록으로 남긴다. 모든 결과물은 한국어로 쓴다.

## [브랜드 이름]은
[한두 줄 소개: 예) 한국 디지털 노마드 커뮤니티. 인스타 @계정]
다루는 주제: [예) 재택·원격근무, 부업, AI 활용, 여행하며 일하기]
형식과 말투: [예) 인스타 카드뉴스와 릴스, 친근한 캐주얼 톤]

## 1. 맥락 파악 (짧게)
- [참고할 자료 폴더 경로: 예) ~/Documents/브랜드/올린 콘텐츠] 의 글을 읽고 지금까지 다룬 주제와 톤을 파악한다.
- ~/.clawd-touchbar/ideas.json 과 [보고서 저장 폴더] 의 최근 보고서 3개를 읽고, 이미 낸 아이디어와 겹치지 않게 한다.
- 다른 작업 주제: ~/.claude/projects/ 아래 최근 3일 안에 바뀐 .jsonl 파일에서 "type":"custom-title" 줄의 customTitle 값을 모아,
  최근 Claude와 하고 있는 일의 주제를 최대 2개 고른다 (이 작업 자신과 일회성 정리 작업은 뺀다).

## 2. 리서치 (웹 검색·페이지 읽기만)
- 최근 7~14일 안의 자료를 우선한다. 공식 트렌드 리포트, 마케팅 매체의 주간 트렌드 글 등을 찾는다.
- 기발한 포맷·훅·편집·오디오 활용을 3~5개 고른다. 공유·저장이 많이 일어나는 유형(정보 저장형, 친구 태그형, 반전·밈형)을 눈여겨본다.
- 조회·공유·저장 수치는 공개된 것만 출처와 함께 적고, 없으면 "공개 수치 없음"이라고 쓴다. 수치를 지어내지 않는다.

## 3. 아이디어 만들기
- [브랜드 이름] 아이디어 3개: 제목(40자 이내), 형식, 첫 3초 훅, 구성(컷이나 슬라이드 4~6개), 캡션 첫 줄과 해시태그, 빌려온 트렌드와 출처 링크.
- 1단계에서 고른 다른 주제마다 아이디어 1개(제목 + 두세 문장).

## 4. 보고서 저장
[보고서 저장 폴더: 예) ~/Documents/브랜드/아이디어 리서치] 에 `YYYY-MM-DD HHmm 트렌드.md` 로 저장한다.
구성: 눈에 띈 트렌드(무엇인지, 왜 먹히는지, 공개 수치, 출처) → [브랜드 이름] 아이디어 → 다른 작업 아이디어 → 한계 메모.

## 5. Clawd에게 전달
~/.clawd-touchbar/ideas.json 을 갱신한다. 기존 파일이 있으면 새 아이디어를 맨 앞에 붙이고 최근 40개만 남긴다. 형식:
{"ideas": [{"id": "YYYYMMDD-HHmm-번호", "topic": "[브랜드 이름] (다른 주제면 그 세션 제목을 짧게)", "title": "40자 이내 한 줄",
 "detail": "120자 이내: 형식·첫 3초 훅·참고 트렌드", "report": "방금 저장한 보고서의 절대 경로", "created": "+09:00이 붙은 ISO 8601 시각"}]}
JSON이 깨지지 않게 같은 폴더에 임시 파일로 먼저 쓰고 이름을 바꿔 덮어쓴다.

## 지킬 것
- 웹은 읽기만 한다. 어떤 계정에도 로그인하지 않고, 아무것도 올리거나 보내지 않는다.
- 위 보고서 파일과 ideas.json 말고는 파일을 만들거나 고치지 않는다.
- 마지막 답변은 이번에 만든 아이디어 제목 3개를 한 줄씩 짧게 적는 것으로 끝낸다.
```
